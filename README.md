# 小红书笔记采集、发布与评论助手

一个纯 Chrome/Edge Manifest V3 扩展，不需要 CLI、服务器或付费 API。它可以采集和归档公开笔记，也提供本地草稿、合规检查、发布页自动填充和评论框自动填充。最终“发布”和“发送”始终由使用者在小红书官方页面确认。

## 发布与评论助手

在扩展弹窗或分析看板中点击“发布与评论助手”。

### 发布草稿

1. 填写标题、正文和标签，草稿会自动保存在浏览器本机。
2. 点击“合规检查”，扩展会检查导流、绝对化、医疗功效、虚假承诺、贬低攻击和诱导互动表达。
3. 点击“打开发布页并自动填充”。
4. 在小红书官方发布页上传自己的图片或视频；如果编辑框尚未出现，点击页面右侧“填入扩展草稿”。
5. 人工核对图片、话题、商业披露和正文后，再由你点击最终“发布”。

### 评论助手

1. 从一篇笔记页面打开助手，或粘贴完整笔记链接。
2. 选择“具体感谢、经验补充、具体提问、回复自己的评论区”等模板。
3. 必须把模板占位符替换成与当前笔记有关的真实细节。
4. 通过检查后，扩展只把内容填进评论框，不会替你点击发送。

评论保护规则：最多准备 10 条/天，相邻两次至少间隔 5 分钟，近期相似度过高的话术会被拒绝；站外导流、收益承诺、互赞互关、医疗功效和攻击性表达会阻止填入。

## 安装

1. 解压下载的 ZIP。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `xiaohongshu-note-extension` 文件夹。
6. 建议把扩展固定到浏览器工具栏。

## 首次准备

在浏览器中打开 `https://www.xiaohongshu.com/` 并完成正常登录。扩展复用浏览器当前登录状态，不读取或导出你的 Cookie。

## 输入关键词找笔记

1. 点击扩展图标，输入关键词，例如“淋浴房”。
2. 设置滚动轮次：每轮会滚动到页面底部等待新内容加载，默认 2 轮。
3. 设置详情数量：从搜索结果靠前的笔记中补采正文、收藏、评论、标签等字段；设为 0 时只采集搜索结果。
4. 设置间隔：默认 12 秒，建议保持 10～20 秒。
5. 点击“开始找相关笔记”。
6. 完成后打开分析看板，可以筛选、排序并导出 CSV。

勾选自动归档后，整批内容只下载一个 ZIP。解压后的结构是：

```text
小红书归档.zip
  小红书归档/
    笔记标题/
      笔记标题.md
      1.jpg
      2.jpg
      3.mp4
```

也可以打开任意笔记详情页，点击“采集当前页并下载一个 ZIP”；或在分析看板中把单篇、当前筛选结果一次性打包。

## 批量采集链接

每行粘贴一个从小红书搜索结果或分享入口取得的完整网页链接。详情读取依赖 `xsec_token`，请勿只粘贴裸笔记 ID，也不要删除链接参数。

## 支持字段

- 笔记 ID、完整链接、来源关键词和搜索排名
- 标题、正文、作者和作者主页
- 点赞、收藏和评论数
- 标签、发布时间和页面可见的 IP 属地
- 图片数量、图文/视频标记和封面链接
- 完整可见图片链接和页面直接提供的可访问视频链接
- 首次发现与最后采集时间

## 数据与权限

- 数据存放在 `chrome.storage.local`，不会上传到服务器。
- 仅请求小红书网页访问、本地存储、标签页和定时任务权限。
- CSV 带 UTF-8 BOM，可直接用 Excel 打开。
- 正文保存为 UTF-8 Markdown，图片和视频在扩展内打包后由浏览器一次性保存。
- 清空数据无法恢复，请提前导出。

## 已知限制

- 小红书页面频繁调整，个别页面实验可能导致某些字段为空。
- 搜索结果是动态瀑布流，滚动轮次相同也可能得到不同数量的笔记。
- 点赞数可能以“1.4万”等缩写展示，扩展会换算为整数。
- 高频搜索或读取详情可能触发安全验证；扩展会暂停，由你手动处理后继续。
- 如果页面播放器只暴露 `blob:` 临时地址、没有可直接访问的视频 URL，扩展不会绕过访问控制，该笔记仍会保存正文和图片。
- 对播放器使用 `blob:`、但页面 `og:video` 元数据提供签名 MP4 的笔记，扩展会优先读取该 MP4 并加入 ZIP。
- ZIP 在浏览器内存中生成；包含很多大视频时建议每批控制在 5 篇左右。
- 不破解验证码、不绕过登录或访问控制，不包含代理池、Cookie 导出、隐身或反检测功能。
- 不提供无人值守发布、批量群发评论、自动点赞关注或自动点击最终提交；这些行为容易误操作，也可能违反平台规则。
- 下载内容可能受著作权和平台规则保护，请仅在你有权使用的范围内保存和使用，不包含去水印功能。
- 使用者应自行确保使用方式符合平台规则及所在地法律；建议以合理频率用于内部研究。
